# Logos de plataformas de streaming

Arquivos PNG com fundo transparente, renderizados em alta resolução a partir de fontes públicas.

## Fontes

- Netflix, Spotify, Max, YouTube Music e Apple TV+: [Simple Icons](https://simpleicons.org/), projeto CC0.
- Amazon Prime Video: [Simple Icons via Iconify](https://icon-sets.iconify.design/simple-icons/primevideo/).
- Disney+ e Globoplay: [Wikimedia Commons](https://commons.wikimedia.org/).

Os logotipos são marcas registradas de seus respectivos proprietários. Este pacote é apenas para conveniência e não implica endosso ou afiliação.
