# QA independente — revisão de quatro eixos

A reprodução de evidências usa parser OOXML XML de XLSX, CSV nativo, JSON nativo e extração de texto PDF. Não executa os scripts produtores para comprovar os mesmos resultados. Os hashes dos arquivos brutos são novamente calculados.

Os runners de regressão e Chrome estão isolados nesta pasta; nenhum relatório da consolidação anterior é sobrescrito. A regeneração adversarial reintroduz os 42 valores de bilhetagem apenas numa cópia isolada, exige reparação automática e igualdade integral ao package integrado.

O Chrome usa o DOM de app.html e o controller real, mas não executa app.js. Portanto, não comprova login nem aplicação completa de ponta a ponta. O cenário móvel emula viewport e rede; não é dispositivo físico. Offline é ativado após assets carregados, verificando fallback local do módulo; não comprova instalação PWA nem primeiro acesso sem rede. Nenhuma captura de tela ou deploy é realizado.

A aprovação das evidências não elimina os limites de competência, universo e revisão de cada fonte. Os nove escalares suspensos de Saúde e a correspondência territorial dos 35 polígonos permanecem suspensos. Divergências anuais SSP2001 devem preservar as duas edições e seus valores brutos.
