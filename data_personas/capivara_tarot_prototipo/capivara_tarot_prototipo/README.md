# Pacote da Capivara Oráculo

Pacote visual para o Tarot das Personas de São José dos Campos.

## Conteúdo

- `expressoes/`: cinco PNGs da personagem com expressões diferentes e fundo transparente.
- `referencia/capivara_sem_fundo.png`: referência-base limpa.
- `documentacao/MANUAL_INTEGRACAO.md`: manual técnico para a IA programadora.
- `documentacao/VALIDACAO_EXPRESSOES.md`: registro de validação dos arquivos.
- `documentacao/limpar_expressoes.py`: limpeza local dos artefatos de transparência.
- `index.html`: protótipo visual anterior da mascote.

## Expressões

1. `01_boas_vindas.png` — abertura.
2. `02_curiosa.png` — leitura e resposta das perguntas.
3. `03_pensativa.png` — interpretação após selecionar uma resposta.
4. `04_surpresa.png` — transição/feedback.
5. `05_celebracao.png` — resultado final.

Leia `documentacao/MANUAL_INTEGRACAO.md` antes de implementar.
